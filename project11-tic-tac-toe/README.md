# Project 11 - Tic Tac Toe Agent

This project is a terminal Tic Tac Toe application where you play against an AI agent.

## Features
- Human vs AI gameplay in the terminal
- Unbeatable AI using minimax with alpha-beta pruning
- Input validation and replay loop

## Run
From the repository root:

```powershell
d:/amzur-chatbot/.venv/Scripts/python.exe project11-tic-tac-toe/tic_tac_toe_agent.py
```

## Controls
- Choose your symbol (`X` or `O`) at startup
- Board positions are numbered left-to-right, top-to-bottom:

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

Type a number from `1` to `9` on your turn.
